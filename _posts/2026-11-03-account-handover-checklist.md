账号交接失败，通常不是忘记了某台机器的 IP，而是恢复邮箱还在离职同事的个人手机上，或者账单告警只发给了已经进不来的那个人。下面是一张跨云清单。各家控制台里怎么点 MFA、怎么建子账号，已经写在单独的笔记里，这里只保留交接时会判错的差别。

## 先交出恢复能力

交接完成的标准是：公司指定的人能够登录、能够重置多因素认证、能够收到账单邮件。做不到这三件，密码本写得再全也没有用。

当天要改到公司控制的位置：

- 登录邮箱的收件箱，包括根用户、主账号和账单备用联系人。
- 绑定的手机号。验证码还打到离职同事的号码上，等于钥匙没交。
- MFA 的种子或通行密钥。放进公司的密码管理器，由至少两名仍在职的人能够取出。不要把二维码发在群里，也不要只存在一个人的个人手机里。
- 根用户或主账号的密码。这是破玻璃用的，不是每天的登录方式。

服务商协助开通时，同样按这四项验收。账号可以请人代办，恢复能力不能长期留在代办的人手里。

Azure 这一行最容易交接错。Microsoft Entra ID 里的全局管理员管的是目录里的用户。订阅上的 Owner 管的是这条订阅里的资源。只把一个人从订阅 IAM 里删掉，他可能仍是全局管理员；只取消全局管理员，他可能仍是订阅 Owner。门户里「订阅 → 访问控制 (IAM)」和「Microsoft Entra ID → 角色和管理员」要各看一次。全局管理员有一项可开启的提升访问权限，用来在紧急时给自己加上订阅管理权。交接后确认这项没有被留在开启状态。说明见[提升全局管理员的访问权限](https://learn.microsoft.com/azure/role-based-access-control/elevate-access-global-admin)。

腾讯云国际的子用户在访问管理 CAM 中维护，和主账号不是同一个登录身份。产品说明见[访问管理](https://www.tencentcloud.com/document/product/598)。

## 先建第二个人，再禁用离职的人

顺序反了，会把自己锁在门外。

1. 用仍在职的人建立一个管理员：阿里云是 RAM 用户，AWS 是 IAM Identity Center 或临时的 IAM 管理员，Google Cloud 是群组上的预定义角色，Azure 是订阅上的 Owner 或用户访问管理员。腾讯云是 CAM 子用户，并带上这个人真正需要的财务权限。
2. 用无痕窗口登录这个新身份，确认 MFA 已绑定，而且能打开账单页面。
3. 再禁用离职者的控制台登录，把他从管理员组移除。
4. 列出他创建的访问密钥、服务账号密钥和 SSH 公钥。密钥只禁用还不够，确认没有流水线仍在使用后删除，并换掉已经写进配置的那一把。
5. 看审计日志里他最近的操作：阿里云用操作审计，AWS 用 CloudTrail，Google Cloud 用管理活动日志，Azure 用活动日志。只在交接前一天出现的新建密钥或安全组放行，要逐条核对。

Google Cloud 上可以用下面的命令核对项目绑定里还有没有这个人：

```bash
gcloud projects get-iam-policy PROJECT_ID
```

Azure 订阅上可以用：

```bash
az role assignment list --assignee USER_OBJECT_ID --all -o table
```

`USER_OBJECT_ID` 从 Entra ID 的用户属性里复制。这条命令看不到他在目录里的全局管理员身份，所以不能代替门户里的第二遍检查。

## 账单通知和发票抬头

告警只发给根用户邮箱时，邮箱一旦停用，超支不会有人知道。五家云的预算都是「发通知」，默认不会停机，见[付款与账单对比]({% post_url 2026-10-30-five-clouds-billing %})。交接时改这三处：

- 账单备用联系人或发票收件人。
- 预算告警的收件邮箱。用角色能够覆盖到的地址，并抄送一个不会随离职停用的邮箱。
- 付款失败时的通知。信用卡即将过期、电汇抬头变更，都不要只留在离职者的个人邮箱里。

发票抬头和签约主体如果还是个人名字，而资源已经是公司的生产环境，趁交接把主体核对清楚。改抬头不一定能追溯到已经开出的发票。

## 可以打印的清单

- 每家云一条记录：账号 ID、登录入口、账单账号 ID、恢复邮箱现在是谁的。
- 主账号、根用户、项目 Owner、订阅 Owner 的 MFA 在公司密码管理器里，并且有第二个人能取出。
- 离职者的控制台用户已禁用，他名下的长期密钥已删除或更换。
- 预算和发票邮件改到在职人员。
- 审计日志里，交接当天的管理员变更能查到操作者。

服务商把账号交回来时，按同一张清单验收，不要只收一个用户名和密码。需要按企业主体协助开通、并把权限交到你指定的人的，看[大牛云的开户说明](https://www.daniucloud.com/open)。
